# 买一排队还是立即买？DOGE 小额订单的成交成本

**决策：默认立即执行已经决定的买单，不启用被动路由。** 本实验优化买价，不产生买入意图，也不估计策略胜率或账户收益。

Cont 与 Kukanov 的[订单放置模型](https://arxiv.org/abs/1210.1625)将排队量、未来成交流、费率以及未成交成本一起纳入决策。由此提出可证伪规则：只有当过去五秒主动卖量足以覆盖当前买一挂量及本单，且点差至少 1 个基点时，才尝试被动买入。五秒是等待预算，不是预测周期。

每分钟第 30 秒生成约 25 USDT 的独立模拟买入意图，固定数量，两条路径均延迟一秒。立即组按当时卖一成交；被动组按决策时买一挂单，若到达时买一已变，则保守地不给被动成交。到达时买一未变，按可见买量排在队尾，同价主动卖单先消耗前排；不因撤单给自己提前。更低价卖盘成交仅按实际成交量折算。五秒到期，假定撤单完成后再过一秒对余量吃卖一；报价超过两秒或挂量不足则最多再等十秒，不能执行单列。两条路径手续费均假设为 0.10%。使用 Tardis 的 Binance 现货 quotes、trades，不使用交易账户。

## 实验

先检验不筛选、每单均排队的版本。2025-11-01、12-01、2026-01-01、02-01 的每单平均节省分别是 −0.220、−0.204、−0.205、−0.476 基点。随后冻结上述点差及前排卖量条件，只在另外三个 UTC 日期测试。正数表示比立即成交便宜。

| 日期 | 有效配对 | 选择排队 | 买便宜 / 买贵 | 全部订单合计节省 USDT |
|---|---:|---:|---:|---:|
| 2026-03-01 | 1,334 | 195 | 97 / 59 | +0.0246 |
| 2026-04-01 | 1,344 | 151 | 60 / 45 | −0.0836 |
| 2026-05-01 | 1,383 | 0 | 0 / 0 | 0 |

共规划 4,320 笔，259 笔因初始行情或可成交量条件未参与配对；进入配对的无未解决余量。346 次尝试中 72 次完全、9 次部分被动成交。买贵的笔数虽少，最差一次多付约 29.60 基点，最终多付 0.0590 USDT。不存在由此支持的独立盈利策略。

约 76.22 个整单等价量被动成交。以每单约 25 USDT 估算，若实际 maker 买入手续费比 taker 低约 0.31 基点，可抵消这三个样本日的模拟差额。这是样本内盈亏平衡敏感性，不是实际费率，更不是上线门槛。数据只含每月一天，未包含交易所真实队列、隐藏量、真实撤单回报、精度过滤及自己的往返延迟；不同费用或执行假设应重新独立检验。不能把省下的手续费当作交易本金的收益。

复跑：项目根目录运行 `python research/hf_passive_entry.py` 和 `python research/hf_passive_entry.py --selective`。系统临时目录的 `moneyrobert-hf-v1` 保存逐单明细，文件名分别为 `passive-entry-events.csv` 和 `selective-entry-events.csv`。
